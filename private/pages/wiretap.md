# THE WIRETAP

This page is where the Office would keep notes on criminal enterprises. The Office is not involved
in any criminal enterprise. The Office is involved in one (1) homepage.

## WHY IT IS ENCRYPTED

Because a wiretap should be encrypted. The Office read this in a tutorial. The tutorial was about
SSL certificates, but the Office understood the spirit of it.

## WHAT IS IN HERE

- the names — redacted
- the dates — approximate
- the invoices — unpaid
- the wire — a metaphor

## HOW TO READ IT

You need JavaScript running and the key from the release. The release is private because it is
called a release. This is the same security model as a diary labelled "diary".

## A WARNING

If you are actually running a wire, do not use this homepage. There is no access control, no audit
log, and no way to revoke a copy. Use a system with a door. This page is a joke about a system
without one.
